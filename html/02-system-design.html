1. 系统概述

1.1 项目背景

CodeGuardian AI 是一个企业级的智能代码审查系统，旨在通过AI技术自动化代码审查流程，提高代码质量，降低安全风险，提升开发效率。

1.2 系统目标

  • 自动化审查 : 支持项目、目录、文件和代码片段的自动化审查

  • 智能分析 : 利用大语言模型（LLM）进行上下文感知的深度代码分析

  • 专业报告 : 生成结构化的审查报告，包含问题详情和修复建议

  • 易于集成 : 提供RESTful API，支持CI/CD流程集成

  • 可扩展性 : 支持规则引擎、RAG增强、Function Calling等高级特性

2.2 分层架构

2.2.1 表现层（Controller Layer）

职责 : 接收HTTP请求，参数验证，响应格式化，权限验证

主要组件 :

  • AuthController: 处理登录、登出、会话管理

  • UserController: 处理用户管理相关请求（CRUD、角色分配）

  • RoleController: 处理角色管理相关请求（CRUD、权限分配）

  • PermissionController: 处理权限查询请求

  • ReviewController: 处理代码审查相关请求（需权限验证）

  • ReportController: 处理报告生成和查询请求（需权限验证）

  • GlobalExceptionHandler: 全局异常处理

  • AuthenticationInterceptor: 认证拦截器（验证登录状态和权限）

设计原则 :

  • RESTful API设计

  • 统一的响应格式

  • 完善的参数验证

  • 跨域支持（CORS）

  • 基于角色的访问控制（RBAC）

2.2.2 业务逻辑层（Service Layer）

职责 : 业务逻辑处理，事务管理，服务编排

主要组件 :

  • AuthService: 用户认证、密码验证、会话管理

  • UserService: 用户管理、用户CRUD、角色分配

  • RoleService: 角色管理、角色CRUD、权限分配

  • PermissionService: 权限查询、权限验证

  • ReviewService: 审查任务编排和管理（需权限验证）

  • AIModelService: AI模型服务统一接口（适配器模式）

  • RemoteModelAdapter: 远程大模型适配器（OpenAI、Claude等）

  • LocalModelAdapter: 本地大模型适配器（Ollama、LocalAI等）

  • ModelConfigService: 模型配置管理、模型切换

  • CodeParserService: 代码文件读取和解析

  • ReportService: 报告生成和格式化（需权限验证）

设计原则 :

  • 单一职责原则

  • 事务边界清晰

  • 异常处理完善

  • 支持异步处理（未来扩展）

  • 权限验证贯穿所有业务操作

2.2.3 数据访问层（Repository Layer）

职责 : 数据持久化，查询优化

主要组件 :

  • UserRepository: 用户数据访问

  • RoleRepository: 角色数据访问

  • PermissionRepository: 权限数据访问

  • UserRoleRepository: 用户角色关联数据访问

  • RolePermissionRepository: 角色权限关联数据访问

  • ReviewTaskRepository: 审查任务数据访问

  • FindingRepository: 审查发现数据访问

  • ReviewReportRepository: 报告数据访问

设计原则 :

  • 使用Spring Data JPA简化开发

  • 自定义查询方法

  • 支持分页和排序

  • 懒加载优化

  • 数据访问权限控制（用户只能访问自己的数据，管理员可访问所有）

2.2.4 数据模型层（Entity Layer）

职责 : 数据模型定义，ORM映射

主要实体 :

  • ReviewTask: 审查任务

  • Finding: 审查发现的问题

  • ReviewReport: 审查报告

2.3 核心模块设计

2.3.1 审查编排模块（Review Orchestrator）

功能 : 审查任务的创建、执行和状态管理

核心流程 :

textjavascripttypescriptcsshtmlbashjsonmarkdownpythonjavaccpprubygorustphpsqlyaml Copy 
                
1. 接收审查请求
2. 创建审查任务（状态：PENDING）
3. 更新任务状态（状态：RUNNING）
4. 调用代码解析服务获取代码内容
5. 调用AI模型服务进行审查
6. 保存审查结果
7. 更新任务状态（状态：COMPLETED/FAILED）
8. 返回任务ID

设计要点 :

  • 任务状态机管理

  • 异常处理和重试机制

  • 支持异步执行（未来扩展）

2.3.2 AI模型服务模块（AI Model Service）

功能 : 与本地和远程LLM服务交互，进行代码审查

架构设计 : 采用适配器模式 ，统一接口支持多种模型：

textjavascripttypescriptcsshtmlbashjsonmarkdownpythonjavaccpprubygorustphpsqlyaml Copy 
                
AIModelService (统一接口)
    ├── RemoteModelAdapter (远程模型适配器)
    │   ├── OpenAIAdapter
    │   ├── ClaudeAdapter
    │   └── CustomRemoteAdapter
    └── LocalModelAdapter (本地模型适配器)
        ├── OllamaAdapter
        ├── LocalAIAdapter
        └── CustomLocalAdapter

核心流程 :

textjavascripttypescriptcsshtmlbashjsonmarkdownpythonjavaccpprubygorustphpsqlyaml Copy 
                
1. 根据配置选择模型类型（本地/远程）
2. 获取对应的模型适配器
3. 构建审查Prompt
4. 调用模型API（本地HTTP或远程HTTP）
5. 解析模型响应（JSON格式）
6. 转换为Finding实体
7. 返回审查结果

设计要点 :

  • 适配器模式 : 统一接口，支持本地和远程模型无缝切换

  • 模型配置 : 支持运行时切换模型，无需重启

  • Prompt模板管理 : 统一的Prompt模板，适配不同模型

  • 响应解析和验证 : 统一的响应格式解析

  • 错误处理和降级策略 : 模型失败时自动切换备用模型

  • 性能优化 : 本地模型低延迟，远程模型高可用

  • 成本控制 : 本地模型零成本，远程模型按需使用

本地大模型支持 :

  • Ollama : 支持本地Ollama服务，兼容OpenAI API格式

  • LocalAI : 支持LocalAI服务，兼容OpenAI API格式

  • 自定义本地模型 : 支持自定义本地模型服务端点

远程大模型支持 :

  • OpenAI : GPT-3.5、GPT-4、GPT-4 Turbo等

  • Claude : Claude 3 Opus、Sonnet、Haiku等

  • 其他兼容OpenAIAPI的服务 : 如Azure OpenAI、Anthropic等

模型切换策略 :

  • 配置驱动 : 通过配置文件选择默认模型

  • 任务级切换 : 每个审查任务可指定使用的模型

  • 自动降级 : 主模型失败时自动切换到备用模型

  • 负载均衡 : 支持多个模型实例负载均衡（未来扩展）

2.3.3 代码解析模块（Code Parser）

功能 : 读取和解析代码文件

支持范围 :

  • 代码片段：直接使用

  • 单个文件：读取文件内容

  • 目录：递归读取目录下所有代码文件

  • 项目：读取项目根目录下所有代码文件

设计要点 :

  • 支持多种编程语言

  • 文件过滤（排除非代码文件）

  • 大文件处理（分块读取）

  • 编码处理（UTF-8）

2.3.4 报告生成模块（Report Service）

功能 : 生成审查报告

报告格式 :

  • HTML格式：用于Web展示

  • Markdown格式：用于文档和版本控制

  • PDF格式：未来支持

报告内容 :

  • 任务基本信息

  • 问题统计（按严重程度、类别）

  • 问题详情列表

  • 修复建议和代码差异

2.3.5 认证授权模块（Authentication & Authorization）

功能 : 用户认证、权限验证、会话管理

核心流程 :

textjavascripttypescriptcsshtmlbashjsonmarkdownpythonjavaccpprubygorustphpsqlyaml Copy 
                
1. 用户登录（用户名/邮箱 + 密码）
2. 验证用户凭证（BCrypt密码验证）
3. 生成会话Token（JWT或Session）
4. 返回用户信息和权限
5. 后续请求携带Token进行权限验证

设计要点 :

  • 密码使用BCrypt加密存储

  • 支持用户名或邮箱登录

  • JWT Token或Session管理

  • 权限拦截器验证每个请求

  • 支持登出和会话失效

2.3.6 用户管理模块（User Management）

功能 : 用户的CRUD操作、角色分配、状态管理

核心功能 :

  • 用户列表查询（支持搜索、筛选、分页）

  • 用户创建、编辑、删除

  • 用户角色分配

  • 用户状态管理（激活/未激活/锁定）

  • 用户信息更新

设计要点 :

  • 用户名和邮箱唯一性验证

  • 密码强度要求

  • 用户状态管理

  • 操作审计日志

2.3.7 角色权限管理模块（Role & Permission Management）

功能 : 角色和权限的CRUD操作、权限分配

核心功能 :

  • 角色列表查询

  • 角色创建、编辑、删除

  • 角色权限分配

  • 权限列表查询

  • 权限验证逻辑

设计要点 :

  • RBAC模型（用户-角色-权限）

  • 角色代码唯一性

  • 权限代码唯一性

  • 预定义角色和权限（ADMIN、REVIEWER、VIEWER）

4. 安全设计

4.1 当前版本安全措施

  • 输入验证 : 使用Spring Validation进行参数验证

  • SQL注入防护 : 使用JPA参数化查询

  • XSS防护 : 报告生成时进行HTML转义

  • 敏感信息 : Git凭据仅会话态，不持久化存储

4.2 未来安全增强

  • 认证授权 : 集成OAuth2/OIDC

  • API限流 : 防止API滥用

  • 审计日志 : 记录所有操作

  • 敏感信息脱敏 : AI请求前进行敏感信息脱敏

  • HTTPS : 生产环境强制HTTPS

  • CORS配置 : 限制跨域访问

模型切换策略 :

  • 任务级切换 : 每个审查任务可指定使用的模型

  • 自动降级 : 主模型失败时自动切换到备用模型

  • 负载均衡 : 支持多个模型实例负载均衡（未来扩展）

1. 系统概述

1.1 项目背景

CodeGuardian AI 是一个企业级的智能代码审查系统，旨在通过AI技术自动化代码审查流程，提高代码质量，降低安全风险，提升开发效率。

1.2 系统目标

  • 自动化审查 : 支持项目、目录、文件和代码片段的自动化审查

  • 智能分析 : 利用大语言模型（LLM）进行上下文感知的深度代码分析

  • 专业报告 : 生成结构化的审查报告，包含问题详情和修复建议

  • 易于集成 : 提供RESTful API，支持CI/CD流程集成

  • 可扩展性 : 支持规则引擎、RAG增强、Function Calling等高级特性
